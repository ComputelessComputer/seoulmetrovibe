# Seoul Metro Vibe

Every train is a note. Every line is an instrument.

Seoul's subway runs without pause — day and night, weekday and weekend. At rush hour, hundreds of trains are moving at once. At 3am, the silences grow longer.

This is what that sounds like.

## Naver Maps

The map is rendered with the Naver Maps JavaScript API. Create a Naver Cloud Maps application with **Dynamic Map** enabled, register the root web domain (`johnjeong.com`), and set `VITE_NAVER_MAPS_CLIENT_ID` in the deployment environment. For local development, copy `.env.example` to `.env.local` and add the Client ID. Do not commit `.env.local`.
